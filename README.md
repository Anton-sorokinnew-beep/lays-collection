# Коллекция Lay’s

Общедоступный фотокаталог личной коллекции. Адаптируется к телефону, планшету и компьютеру. Поиск по вкусу, стране и виду чипсов; комбинируемые фильтры; сортировка; крупные фото и ссылки на отдельные упаковки.

## Источник данных

Действующий Excel-каталог проекта: `outputs/01a1bbcd-8dff-7bc3-92f3-60a1d71522b8/Коллекция Lay’s.xlsx`. Оригиналы находятся в `Фото/<Страна>/`. Они остаются в основном локальном проекте. В репозиторий сайта попадают только сведения о коллекции и облегчённые WebP-копии без EXIF-метаданных. Одна строка каталога — одна упаковка; варианты одного вкуса учитываются отдельно.

## Просмотр локально

Из папки этого репозитория:

```sh
python3 -m http.server 4173 --directory public --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Сервер сборки и база данных не нужны.

## Обновление коллекции

1. Добавьте фото в исходный проект и запись в действующий Excel-каталог.
2. Экспортируйте изменения (нужны Python 3.10+ и Pillow):

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_catalog.py --source-root "/путь/к/Коллекция"
node --test tests/catalog.test.mjs
```

Если репозиторий находится внутри исходной папки «Коллекция», `--source-root` можно опустить. Для другого расположения действующего каталога используйте `--catalog "/путь/каталог.xlsx"`.

3. Сохраните изменения в Git и отправьте их в `main`. GitHub Actions проверит данные и опубликует папку `public`.

Изменение локального Excel-файла само по себе не обновляет опубликованный сайт: необходимы экспорт и отправка в GitHub.

Для сортировки по дате у каждой упаковки хранится `addedAt`. У исходных 360 упаковок это время первой публикации сайта — 8 ноября 2026 года. Экспорт сохраняет даты существующих упаковок по их ID, а новым назначает время первого экспорта в каталог сайта. Повторная сборка даты не меняет. Дата добавления показана в карточке; сортировка поддерживает «Сначала новые» и «Сначала старые».

## Публикация на GitHub Pages

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует сайт при изменениях в `main` и поддерживает ручной запуск. Настройка не требует токенов или секретов в файлах проекта.

Адрес проекта после успешной публикации: https://anton-sorokinnew-beep.github.io/lays-collection/

Все ссылки на ресурсы относительные, поэтому сайт работает и по этому адресу, и на собственном домене. Сайт не использует внешние шрифты, аналитику, cookies или сторонние библиотеки.

## Проверка

```sh
node --test tests/catalog.test.mjs
```

Проверяются наличие изображений, счётчики, комбинации фильтров, поиск с `ё/е`, варианты упаковок и сохранение фильтров в ссылках.
